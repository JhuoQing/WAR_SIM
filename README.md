# 海峽戰術 WAR_SIM

網頁版台海戰爭推演遊戲。真實地圖、戰前部署陸海空、按下「戰爭開始」後自動推演。

> 目前版本 **v0.2：部署階段**。推演引擎（新聞快報、動態戰場、勝負判定）將在 v0.3 加入。

## 怎麼玩
直接用瀏覽器打開 `index.html`，不需安裝。

1. 右側選兵種分類（陸軍／海軍／空軍／防空與飛彈）→ 點兵種 → 點地圖放置（可放的地方會發光）
2. 拖曳單位可移動，右鍵單位撤回退款，滾輪縮放、拖曳地圖平移
3. 分配 **日美協防預備金**（虛構設定）：投入越多外援越早、越強，但必須守住首都撐到外援抵達
4. 看「部署評估」找弱點，參考「情報估計」判斷敵方可能的登陸方向
5. 按 **戰爭開始**

### 部署規則
| 類型 | 可部署位置 |
|---|---|
| 陸軍、防空、雷達、無人機 | 台灣本島與離島陸地 |
| 岸置反艦飛彈 | 離海岸 15 km 內 |
| 艦艇、潛艦 | 我方海域（虛線以東） |
| 戰機中隊 | 空軍基地（每基地最多 3） |
| 水雷區 | 灘頭外海（每灘頭最多 2） |

## 檔案結構
- `index.html` / `style.css`：介面
- `js/data.js`：兵種、防區、灘頭、基地、協防、難度等遊戲資料
- `js/app.js`：地圖繪製、部署互動、預算、評估
- `data/map-data.js`：地圖資料（由 `tools/build_map.py` 產生）
- `legacy/v0.1/`：舊版回合制六角格原型

## 地圖資料來源
- 中國大陸海岸：[Natural Earth](https://www.naturalearthdata.com/)（公共領域）
- 台灣縣市界：[g0v twgeojson](https://github.com/g0v/twgeojson)（內政部開放資料）
