# 海峽戰術 WAR_SIM

網頁版台海戰爭推演遊戲：真實地圖、戰前部署陸海空、按下「戰爭開始」後自動推演，新聞快報與戰場即時動態顯示。

> 目前版本 **v0.3**：部署 + 自動推演 + 勝負判定，深色／淺色模式。

## 怎麼玩
直接用瀏覽器打開 `index.html`，不需安裝。

1. **部署**：右側選分類 → 點兵種 → 點地圖放置（可放的地方會發光）。拖曳移動、右鍵撤回、滾輪縮放、拖曳平移，左上「⟲ 重置視角」回到預設畫面
2. 分配 **日美協防預備金**（虛構設定）
3. 看「部署評估」找弱點、參考「情報估計」
4. 按 **戰爭開始** → 3 秒倒數 → 自動推演（可暫停、1x／2x／4x、⏭ 直接算結果）
5. 結算畫面可「同部署再戰一次」（每次結果有隨機差異）

## 推演流程（1 遊戲小時 = 1 tick，最長 10 天）
| 時間 | 事件 |
|---|---|
| D+0 起 | 飛彈齊射（機場、雷達、防空、城市），防空攔截；空戰爭奪制空權 |
| D+0 04:00 | 敵軍登陸金門、馬祖 |
| D+0 20:00 | 第一波登陸船團出港，依「我方部署弱點 × 情報方向」選 2～3 個灘頭 |
| 渡海途中 | 岸置反艦飛彈、多管火箭、艦艇、潛艦、戰機、無人機攻擊船團；護航艦隊攔截與反擊 |
| 抵達灘頭 | 水雷、灘頭守軍與砲兵射擊，剩餘兵力上岸 |
| D+2 22:00 | 第二波船團增援灘頭（或另選新灘頭） |
| 陸戰 | 防區內交戰（地形加成、制空權、砲兵支援、在地守備），我軍自動調動增援與反擊，敵軍向首都推進 |
| D+4／D+7 | 若有協防預備金，判定日美協防是否抵達 |

重要機制：
- **隱蔽**：機動單位（反艦飛彈、火箭、步兵）平時難被鎖定，開火後暴露 3 小時
- **在地守備**：每個防區都有不需購買的守備兵力，守備與駐軍全滅才會失守
- **協防**：首都失守則取消；抵達後大幅削弱敵方空軍、船團與作戰意志

## 勝負判定
| 結局 | 條件 |
|---|---|
| 守方大勝 | 登陸部隊大多在海上被殲滅（上岸 < 25%），或攻方意志崩潰且無失土 |
| 守方勝 | 登陸部隊全數被殲滅、攻方意志歸零撤軍，或撐過 10 天無失土 |
| 僵持停火 | 10 天後敵方控制 1～2 個防區（首都未失） |
| 守方敗 | 首都失守、社會韌性歸零被迫談判，或 10 天後失去 3 個以上防區 |
| 守方大敗 | 首都失守且敵方控制 5 個以上防區 |

- **社會韌性**：城市遭飛彈命中、防區失守（首都 −40）會下降；擊沉船團、收復失土會回升
- **攻方作戰意志**：兵力、艦艇、戰機損失會下降；D+5 後國際壓力持續下降；佔領防區會回升

金門、馬祖失守不直接決定勝負，但會降低社會韌性。

## 平衡測試
```
node tools/sim_test.js 200 normal
```
批次跑 AI 推演，比較不同部署策略與難度的勝率。

## 檔案結構
- `index.html` / `style.css`：介面（含淺色模式）
- `js/data.js`：兵種、防區、灘頭、基地、協防、難度
- `js/core.js`：地理運算、部署規則、推薦部署
- `js/engine.js`：戰爭推演引擎（純邏輯，可在 node 執行）
- `js/app.js`：地圖繪製、部署互動、戰爭畫面、新聞快報、結算
- `data/map-data.js`：地圖資料（由 `tools/build_map.py` 產生）
- `legacy/v0.1/`：最早的回合制六角格原型

## 地圖資料來源
- 中國大陸、日本、菲律賓海岸：[Natural Earth](https://www.naturalearthdata.com/)（公共領域）
- 台灣縣市界：[g0v twgeojson](https://github.com/g0v/twgeojson)（內政部開放資料）
